## Branch-specific project bullets

**IT / CSE:** web or mobile apps, APIs, ML models with accuracy, competitive programming ratings, open-source contributions.

**ECE / EEE:** "Designed an IoT soil moisture monitor with ESP32 and sensors; cut water use by about 30% in a 2-acre trial plot." Tools: MATLAB, Arduino, Verilog, PCB design.

**Mechanical:** "Redesigned a fixture in SolidWorks that reduced machining setup time by 15% during internship at an auto parts plant." Tools: AutoCAD, SolidWorks, ANSYS, CNC basics.

**Civil:** "Prepared bar bending schedules and quantity estimates for a G+4 building during site internship." Tools: AutoCAD, STAAD Pro, MS Project.

## Tips

- Skills right after the summary: IT recruiters search by technology
- GitHub link with tidy READMEs
- Only list skills you can answer interview questions on
- One page

Google Docs is free and works on a phone, which makes it a common choice. Some of its built-in resume templates use layout tables or side columns, so a blank page is the safer start.

## Step by step

1. **New document.** Go to docs.google.com and open a blank document.
2. **Margins.** File > Page setup > margins of 0.5 to 0.75 inches (about 1.3 to 1.9 cm).
3. **Font.** Arial, Calibri or Lato, 10.5 or 11 pt for body text. Line spacing 1.0 to 1.15.
4. **Name.** Type it on the first line, 18–22 pt, bold.
5. **Contact line.** On the second line, in the body (not the header area): city | email | phone | LinkedIn.
6. **Section headings.** Type "Summary", "Experience", "Education", "Skills". Set each to Heading 2 so they're consistent. Add a horizontal line under each if you like (Insert > Horizontal line).
7. **Job entries.** Bold the job title and company on one line; dates and city on the next.
8. **Bullets.** Use the bullet list button. Start each bullet with a verb and include a number where you can.
9. **Check length.** One page for most people under about 8 years of experience.
10. **Download.** File > Download > PDF document (.pdf). Name it `Firstname-Lastname-Resume.pdf`.

## Things to avoid in Docs

- Templates with a sidebar or two columns
- Inserting a table to line things up
- Putting your details in Insert > Headers & footers
- Text boxes from the Drawing tool

## Test it

Open the downloaded PDF, select all text, copy it into a plain text editor and read it top to bottom. If anything is out of order, simplify the layout. Full checklist: [ATS-friendly resume](/articles/how-to-make-resume-ats-friendly/).

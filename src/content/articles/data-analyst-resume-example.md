## Sample bullets

**Experienced analyst**
- Built a weekly sales dashboard in Power BI from 6 SQL sources, used by 40 store managers and cutting manual reporting by 60%
- Analysed 18 months of promotion data in Python, showing 3 of 9 promo types lost money; the team dropped them, saving about ₹1.2 crore a year
- Designed an A/B test for a new checkout flow that lifted conversion by 4.2%
- Automated monthly finance reconciliation with SQL and Excel, saving 2 days of work each month

**Entry level (projects)**
- Analysed 120,000 rows of public bike-share data in SQL to find peak-hour shortages by station; presented recommendations in Tableau
- Cleaned and modelled 3 years of a family shop's sales in Excel to plan stock for the festive season; reduced stock-outs on top items
- Built a churn prediction model in Python (scikit-learn) on a public telecom dataset with 81% accuracy

## Skills section

- **Querying:** SQL (joins, window functions, CTEs)
- **Analysis:** Python (pandas), R, Excel (pivot tables, XLOOKUP, Power Query)
- **Visualisation:** Power BI, Tableau, Looker Studio
- **Methods:** A/B testing, regression, cohort analysis, forecasting

## The bullet pattern

**Business question → method and tool → result or decision.**

"Why are returns rising?" → "Analysed 50,000 return records in SQL by product and courier" → "Found one courier caused 30% of damage returns; switching cut returns by 12%."

## What hiring managers look for

1. Can you write SQL without help?
2. Do you communicate findings to non-technical people?
3. Did your analysis change a decision?

## Entry-level tips

- Use public datasets and say so
- Link a portfolio or GitHub with notebooks and dashboards
- Show one end-to-end project: question, data cleaning, analysis, recommendation

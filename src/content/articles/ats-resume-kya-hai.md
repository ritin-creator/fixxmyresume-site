Jab aap Naukri, LinkedIn ya company website par apply karte ho, aapka resume pehle ek software mein jaata hai jise **ATS** kehte hain. Ye software aapka naam, phone, email, job titles, companies, dates aur skills nikaal kar save karta hai. Recruiter phir isme search karta hai, jaise "Accounts Executive" + "Tally".

Agar software ne aapka resume galat padha, ya usme sahi keywords nahi hain, to aap search mein dikhoge hi nahi.

## Resume ATS mein kyon fail hota hai

| Galti | Kya hota hai |
| --- | --- |
| Do column wala template | Dono columns ki lines mix ho jaati hain |
| Table ya text box | Andar ka text skip ho sakta hai |
| Phone/email header mein | Kuch software header padhte hi nahi |
| Icons, photo, skill bars | Software padh nahi sakta |
| Scan kiya hua PDF | Usme text hai hi nahi, sirf image hai |
| Alag-alag date format | Experience galat calculate ho sakta hai |

## ATS friendly resume ke 7 rules

1. Ek column
2. Headings: Summary, Experience, Education, Skills, Projects
3. Naam aur contact page ke andar, header mein nahi
4. Arial ya Calibri font
5. Dates ek hi format mein: "Jan 2024 – Present"
6. Job description ke keywords (jo sach mein aapke paas hain)
7. Text wala PDF ya Word file

## Ek simple test

Apna PDF kholo, sab text select karke copy karo aur Notepad mein paste karo. Agar text ulta-pulta aaya ya kuch gayab hai, to ATS ko bhi problem hogi.

## ATS score kaise badhaye

ATS score har tool alag tarike se nikaalta hai. Lekin sabse zyada farak in cheezon se padta hai: saaf format, job title summary mein, skills job ke hisaab se, aur har point mein number.

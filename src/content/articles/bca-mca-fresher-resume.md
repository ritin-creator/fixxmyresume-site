## Summary examples

- "BCA 2026 graduate seeking a junior web developer role. Built a PHP and MySQL inventory system for a local pharmacy that tracks 1,500 products."
- "MCA 2026 graduate seeking a Java developer role, with a 6-month internship building REST APIs in Spring Boot and a GitHub portfolio of 4 projects."

## Project bullets (fictional)

- **Pharmacy Inventory System** | PHP, MySQL, Bootstrap: tracks 1,500 products and expiry dates; owner now gets low-stock alerts by email
- **Student Attendance App** | Android (Kotlin), Firebase: used by 3 classes (120 students) for a semester
- **Expense Tracker API** | Java, Spring Boot, PostgreSQL: REST API with JWT login and 25 unit tests
- **Sales Dashboard** | Python, pandas, Power BI: analysed a public retail dataset of 50,000 orders

## Skills to list

- **Languages:** Java, Python, C, JavaScript, PHP
- **Web:** HTML, CSS, React, Node.js, Spring Boot, Django
- **Databases:** MySQL, PostgreSQL, MongoDB
- **Tools:** Git, GitHub, Postman, VS Code, Linux basics
- **Testing:** manual testing, Selenium basics, test cases

## Roles to target

Junior developer, web developer, software tester (QA), technical support, application support, data analyst trainee.

## Competing with B.Tech candidates

Some employers prefer B.Tech for certain roles, but many hire BCA and MCA graduates when the skills are there. A working project with real users, clean code on GitHub, and a certification (cloud, testing or a language) make up the difference.
